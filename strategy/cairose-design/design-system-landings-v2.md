# Cairose — Design system (landings marketing) v2

**Product:** White-label flower-subscription platform for florists. Cairose does NOT sell flowers. Dual landings: A `/` floristería · B `/para-ti` persona.

**Thesis v2 (post Daniela reject):** Not a SaaS landing in warm paint. A florist atelier editorial — magazine photo, ink display, paper proof. If it could be a B2B tool homepage with different copy, it fails.

**Banned:** lilac, purple SaaS, glass, orbs, dark tech.

## Typography v2 (REOPEN — Fraunces rejected as not selling)

| Role | Family | Notes |
|------|--------|-------|
| Wordmark | Sora | lowercase `cairose` only — quiet |
| H1 / display | **Cormorant Garamond** 600–700 | Atelier editorial; large optical size |
| Body | Inter or system humanist | Quiet utility — never the personality |
| Emphasis | teja on key word (`tu`) | Not script gimmick |

**Anti-SaaS type:** No Inter/Sora as H1. No “startup display”. Tracking and scale like a printed carta, not a dashboard.

## Composition anti-SaaS

- Hero = full-bleed editorial photograph (workshop/hands/materials). Copy overlays air in the photo — NOT a two-column product hero with empty image well.
- No pill-stack CTAs that read Linear/Attio. Primary CTA can be a solid oliva rectangle or ink underline button — craft, not soft-pop pills.
- Header: minimal wordmark + one link + one CTA; no “product nav” density.
- White-label proof ONLY below fold as paper menu/carta (Casa Limón). Never browser.
- Scenes as magazine modules / irregular columns — never 3 equal feature cards.
